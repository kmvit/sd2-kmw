### Сборка

Шапка, футер, форма заявки и мобильное меню лежат в `src/partials/` в одном
экземпляре, контент страниц — в `src/pages/`. Готовые HTML в корне
**генерируются** и коммитятся вместе с исходниками:

```bash
python3 build.py
```

Правки вносим в `src/`, не в корневые файлы — иначе их затрёт следующая сборка.
Метаданные страницы (title, description, активный пункт меню) задаются блоком
`<!--meta ... -->` в начале файла в `src/pages/`.

**Два режима сборки.** По умолчанию сайт закрыт от поисковиков: в каждую
страницу подставляется `<meta name="robots" content="noindex, nofollow">` и
пишется запрещающий `robots.txt`. Это режим тестовой площадки. Для боевого
домена собираем с флагом:

```bash
python3 build.py --prod
```

```
build.py                 сборщик страниц
deploy.sh                выкладка на тестовый сервер
shots.py                 съёмка страниц в JPG для заказчика
src/partials/            шапка, футер, форма, меню, общий скрипт
src/pages/               контент страниц
*.html                   собранные страницы (генерируются)
static/assets/site.css   дизайн-система «Стройдеталь-2»
static/img/              фотографии завода, сертификаты, логотипы, портреты
favicon.ico              иконка сайта (плюс static/favicon.svg и apple-touch-icon)
robots.txt               генерируется build.py
docs/                    аналитика и решения по проекту
docs/mockups/            JPG-макеты страниц (генерируются)
```

### Макеты в JPG

Для передачи заказчику страницы снимаются целиком — десктоп 1600 px и мобильный
390 px (Retina), нумерация файлов повторяет порядок разделов сайта:

```bash
python3 shots.py
```

Снимки складываются в `docs/mockups/desktop/` и `docs/mockups/mobile/`. Одну
страницу можно переснять по имени: `python3 shots.py index zhbi`. Сервер
поднимается и гасится скриптом, отдельно запускать ничего не нужно.

## Дизайн-система

Родственна системе ГАНИН ГРУПП «Монолит» — та же сетка, та же типографическая
логика, та же индустриальная подача. Своё у Стройдетали:

| | ГАНИН ГРУПП | Стройдеталь-2 |
|---|---|---|
| Акцент | оранжевый `#FF6A00` | заводской синий `#1B72D4` |
| База | нейтральный графит `#111111` | холодный сине-графитовый `#0D1217` |
| Заголовки | Oswald | Fira Sans Condensed |
| Текст | Inter | Golos Text |
| Подписи | JetBrains Mono | IBM Plex Mono |
| Продукция | фото-мозаика плиток | строки-реестр с фото и тегами |
| Разметка секций | нумерация `02 / 12` | штамп с подписью слева |

Красный `#D9372B` из логотипа используется точечно — только в знаке «СД2».

## Важное по содержанию

**Цены закрыты не везде.** На бетоне, растворах, асфальте и ЖБИ стоят «По
запросу» и «Договорная» — так на текущем sd2-kmv.ru. Но на странице карьера
прайс **открыт**: щебень и песок от 275 до 520 ₽/т. Эти цены перенесены в
макет как есть. Если завод решит открыть остальные прайсы, таблицы готовы их
принять — колонка «Цена» уже размечена.

**Фотографии — частью временные.** Снимки производства взяты со старого сайта,
часть из них устарела; для продакшена нужна съёмка: производство, лаборатория,
готовая продукция, объекты из нашего бетона.

Что уже заменено свежими материалами с сайта группы `ganin-group.ru`:

| Где | Файл | Источник |
|---|---|---|
| Портреты шести руководителей | `static/img/team/gg-*.jpg` | блок «Команда» |
| Слово собственника на главной | `static/img/team/gg-director.jpg` | блок «Команда» |
| Автопарк на главной и шапка доставки | `static/img/avtopark-sitrak.jpg` | страница «Логистика» |

Все шесть портретов в блоке команды — из свежей съёмки группы. Мелкие снимки
со старого сайта (210 × 315 px) в макете больше не используются.

**Команда на `kontakty.html` идентична блоку «Команда» на `ganin-group.ru`:**
те же шесть человек, тот же порядок, те же должности и портреты — у завода и
группы команда общая. Сотрудники со старого сайта СД2, которых нет на сайте
группы (Литвинова, Горжий, Клиновая, Набоков), из блока удалены.

У Ганина Алексея Михайловича и Александровой Марины прямых номеров нет ни в
одном источнике — в карточках стоит «телефон уточняется». Согласие сотрудников
на публикацию прямых номеров нужно подтвердить у завода.

Телефон отдела продаж (+7 928 821-72-11) остаётся в первом блоке страницы, в
шапке и в футере, а прямой контакт начальника карьера — на `karer.html`.

Два расхождения со старым сайтом сверены по сайту группы: должность Диденко —
«начальник отдела снабжения» (в alt-тексте старого сайта стояло «И.О.
начальника ССиОП»); главный бухгалтер на старом сайте — Орехова Любовь
Михайловна, на `ganin-group.ru` — Кулаковская Любовь Михайловна. В макете стоит
актуальная фамилия Кулаковская — подтвердить, что это один человек.

**Каталог ЖБИ.** В макете открыта одна образцовая карточка товара — тротуарная
плитка. Остальные 18 групп ведут на форму заявки; при переносе на CMS каждая
получит свою страницу. Полные таблицы характеристик по всем группам есть на
старом сайте по адресам `/zhelezobeton/<товар>` — оттуда их и берём при
вёрстке карточек. Две цифры в этом источнике противоречивы и требуют сверки с
заводом: объём бетона лотка Б-7 (0,0125 м³ при весе 300 кг) и длина
прикромочного лотка Б1 (в таблице 1000 мм, в тексте «всего 330 мм», артикул
Б 1/0,33). Ещё 7 групп на старом сайте
закомментированы и отдают 301 на каталог — ступени, многопустотные плиты,
перемычки, колодцы связи, лестничные марши, шпалера, щелевые полы. Уточнить
у завода, возвращать ли их.

**Противоречие в цифрах.** На главной старого сайта — «25 собственных
автомиксеров», на странице бетона — «более 30 единиц». В макете везде 25;
нужно уточнить актуальное число.

**Сертификаты просрочены — требуется замена до продакшена.** Сканы в блоке
`#certs` взяты со старого сайта; при разборе выяснилось:

|---|---|---|
| `sertif-1` | Смеси бетонные тяжёлые, ГОСТ 7473-2010 | до 03.09.2017 |
| `sertif-2` | Плиты ЖБ для городских дорог, ГОСТ 21924.0-84 | до 09.09.2017 |
| `sertif-3` | Плиты бетонные тротуарные, ГОСТ 17608-91 | до 03.09.2017 |

Плюс на старом сайте **подписи не совпадают со сканами**: песок подписан как
«камни бетонные бортовые», щебень — как «песок», а шестой файл оказался
побайтовым дублем песка. Сертификата на бортовой камень в наличии нет вовсе.
В макете подписи исправлены по самим сканам, дубль удалён. У завода нужно
запросить действующие документы.

**Логотипы партнёров** (`static/img/partners/`) — поставщики сырья и техники:
Teka, ZENITH, CIFA, Demag, Rampf, Probst, Евроцемент, ВЦ «Кавказ», Sika,
MC-Bauchemie, Bayer. Файлы мелкие (100 px), для продакшена нужны векторы.
Подписи под логотипами проставлены по названиям брендов — уточнить у завода,
особенно ВЦ «Кавказ».
