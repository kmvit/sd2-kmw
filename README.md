# Сайт ЗАО «Стройдеталь-2» — редизайн

Этап 3 договора с ГАНИН ГРУПП: редизайн sd2-kmv.ru на дизайн-системе группы.

## Что здесь сейчас

Этап 3.2 — дизайн UI. Свёрстан макет главной страницы.

```
index.html               главная страница
static/assets/site.css   дизайн-система «Стройдеталь-2»
static/img/              фотографии завода (взяты с текущего sd2-kmv.ru)
docs/                    аналитика и решения по проекту
```

## Дизайн-система

Родственна системе ГАНИН ГРУПП «Монолит» — та же сетка, та же типографическая
логика, та же индустриальная подача. Своё у Стройдетали:

| | ГАНИН ГРУПП | Стройдеталь-2 |
|---|---|---|
| Акцент | оранжевый `#FF6A00` | заводской синий `#1B72D4` |
| База | нейтральный графит `#111111` | холодный сине-графитовый `#0D1217` |
| Заголовки | Oswald | Fira Sans Condensed |
| Текст | Inter | Golos Text |
| Подписи | JetBrains Mono | IBM Plex Mono |
| Продукция | фото-мозаика плиток | строки-реестр с фото и тегами |
| Разметка секций | нумерация `02 / 12` | штамп с подписью слева |

Красный `#D9372B` из логотипа используется точечно — только в знаке «СД2».

## Запуск превью

```bash
python3 -m http.server 8787 --directory .
```

## Важное по содержанию

**Цен на сайте нет.** На текущем sd2-kmv.ru все прайсы скрыты: «По запросу»,
«Договорная», «- руб.». Поэтому главная построена вокруг быстрого запроса
расчёта, а не вокруг прайса. Если завод решит открыть цены — блок продукции
готов их принять (в строках реестра предусмотрено место).

**Фотографии — временные.** Взяты со старого сайта, часть снимков устарела.
Для продакшена нужна съёмка: производство, лаборатория, готовая продукция,
объекты из нашего бетона.
