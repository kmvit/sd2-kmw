# Вёрстка корпоративного сайта

Статические страницы, собираются из общих частей скриптом на Python.
Зависимостей у сборки нет, для съёмки макетов нужен Playwright.

## Запуск

```bash
python3 build.py                 # собрать страницы
python3 -m http.server 8787      # открыть http://localhost:8787
```

Правки вносим в `src/`, корневые `*.html` генерируются и затираются сборкой.

Сборка без флага закрывает сайт от поисковиков — мета-тег `noindex` в каждой
странице и запрет в `robots.txt`. Для боевого домена:

```bash
python3 build.py --prod
```

## Структура

```
build.py                 сборщик страниц
deploy.sh                выкладка на сервер
shots.py                 съёмка страниц в JPG
src/partials/            шапка, футер, форма заявки, мобильное меню, скрипты
src/pages/               контент страниц, метаданные в блоке <!--meta ... -->
*.html                   собранные страницы (генерируются)
404.html                 страница ошибки, собирается отдельно
robots.txt               генерируется build.py
favicon.ico              иконка, рядом static/favicon.svg и apple-touch-icon
static/assets/site.css   дизайн-система
static/img/              фотографии, сертификаты, логотипы, портреты
docs/                    заметки по проекту, docs/mockups/ вне репозитория
```

Служебные комментарии из `src/` в собранные страницы не попадают — сборщик их
вырезает.

## Съёмка макетов

```bash
python3 shots.py                 # все страницы, десктоп 1600 px и мобильный 390 px
python3 shots.py index           # одну страницу
```

Снимки складываются в `docs/mockups/`, сервер поднимается скриптом.

## Выкладка

```bash
./deploy.sh                      # собрать и залить
./deploy.sh --prod               # то же, с открытой индексацией
```

Адрес и каталог задаются переменными `SD2_HOST` и `SD2_DEST`. На сервер уезжают
только страницы, `static/`, иконки и `robots.txt`.

Что доделать до переезда на боевой домен — в [docs/notes.md](docs/notes.md).
